# Phantom — Страница загрузок

Этот небольшой статический сайт служит для распространения бинарных сборок приложения Phantom.

Файлы:

- `index.html` — главная страница со ссылками на загрузки.
- `styles.css` — стили сайта.
- `downloads/` — директория для размещения файлов сборки и контрольных сумм.

Как использовать (локально):

1. Поместите реальные бинарники в `downloads/` с именами:
   - `phantom-windows.exe`
   - `phantom-mac.dmg`
   - `phantom-linux.tar.gz`

2. Обновите контрольные суммы в `index.html` или создайте `downloads/checksums.txt` с SHA-256 значениями.

3. Запустите простой статический сервер (пример для PowerShell):

```powershell
 # Через Python (если установлен корректно):
 py -3 -m http.server 8000
 # или, если установлен Node.js (рекомендованный вариант на этой машине):
 npx http-server -p 8000
```

4. Откройте в браузере `http://localhost:8000`.

Замечания:
- Заменяйте плейсхолдерные файлы в `downloads/` на реальные сборки перед публикацией.
- По желанию разместите сайт на GitHub Pages, Netlify или любом другом статическом хостинге.

 Дополнительно — логотип и одиночная кнопка Windows

 - Логотип: файл с логотипом лежит в `assets/logo.svg`. Чтобы заменить логотип — просто поместите вашу картинку с именем `logo.svg` в папку `assets/` (можно сохранить как PNG, но рекомендуется SVG).
 - Сейчас на странице доступна только кнопка загрузки для Windows (`downloads/phantom-windows.exe`). Остальные платформы скрыты по просьбе.

- Логотип: поддерживаются форматы `SVG`, `PNG` и `ICO`.
   - Для отображаемого логотипа используйте `assets/logo.png` (предпочтительно PNG) или `assets/logo.svg`. Если `logo.png` доступен, сайт попытается загрузить его с автоматическим cache-busting; при ошибке загрузки произойдёт откат к `logo.svg`.
   - Favicon: можно заменить `assets/favicon.ico` или `assets/favicon.svg`.
   - Favicon: теперь рекомендуется просто положить `assets/favicon.png` (или `favicon.ico` / `favicon.svg`). Сайт автоматически использует `favicon.png` если он есть и добавляет cache-busting, поэтому достаточно заменить файл — браузер подтянет новый значок при следующей загрузке.

 Если нужно, могу добавить форму для загрузки логотипа или скрипт, который автоматически генерирует миниатюру и обновляет страницу.
